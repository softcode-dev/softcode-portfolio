# softcode-portfolio

Monorepo for the Softcode portfolio project.

## Structure

- `frontend/` — React app (Vite)
- `backend/` — Node.js + Express API

## Frontend

```bash
cd frontend
npm install
npm run dev
```

## Backend

```bash
cd backend
npm install
npm run dev
```

The API runs on `http://localhost:5000` by default.
